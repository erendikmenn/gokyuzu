# Contributing to Gökyüzü

Thank you for helping! Gökyüzü is a free flight simulator for the browser, and it has to run well on a phone. This file
explains how to set up, what we expect in a pull request, and the few rules that keep the project fast, legal and
private. A short Turkish version is at the end ([Türkçe](#türkçe)).

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md). Security problems go through GitHub's private
reporting, never a public issue: see [SECURITY.md](SECURITY.md).

## Ways to help

- **Try it and report:** bugs, and above all performance on your devices (Windows laptops, Android phones, Firefox).
  Use the issue templates: they ask for the device, browser, map and aircraft.
- **Pick a starter task:** [docs/good-first-issues.md](docs/good-first-issues.md) lists concrete tasks with the files
  involved and how to check the result.
- **Propose a mission or a map area** (see [below](#proposing-missions-and-maps)).
- **Code:** flight models, avionics, missions, UI, accessibility, translation, tools.

For anything bigger than a small fix, open an issue first so we can agree on the approach before you spend time on it.

## Setting up

You need Node.js 20 or newer and git. The game code is plain ES modules served as they are: there is no build step for
development.

```sh
git clone https://github.com/erendikmenn/REPO_NAME.git
cd REPO_NAME
npm install
```

The game assets (about 2.8 GB of models, textures, map tiles and sounds) are not in git. Get them in one of two ways:

- **The asset pack** (recommended for regular work): `node tools/assets/fetch_pack.mjs` downloads the trademark-free
  asset pack from the repository's GitHub Releases and verifies it. Then run `node tools/serve.mjs`.
- **On demand, for a fast start:** `node tools/serve.mjs --assets-from https://fs.erenailab.com` fetches each file the
  game asks for from the live site, once, and caches it in `.cache/assets/`. Please keep it to normal play and
  testing: no scripted bulk downloads. The live site's files are for developing and testing this project only; they
  may include brand liveries that are not part of the pack or its licence.

Then open http://localhost:5173/. The README explains [how assets work](README.md#how-assets-work) and how to
[rebuild them from source](README.md#rebuilding-the-assets).

Useful URL parameters: `?map=ist`, `?aircraft=f16&spawn=AIR-GGB`, `?mission=ist-halic`, `?quality=low`,
`?device=phone&touch=1` (phone profile on a desktop browser), `?fps=30`. Usage beacons are off on `localhost`; add
`&telemetry=0` anyway when you test against another host.

## Developer Certificate of Origin (DCO)

We use the [Developer Certificate of Origin 1.1](https://developercertificate.org/) instead of a contributor licence
agreement. By signing off a commit you certify that you wrote it, or otherwise have the right to submit it under the
project's licences. Sign off every commit:

```sh
git commit -s -m "Missions: …"
```

This adds a line with the name and e-mail address of your git identity:

```
Signed-off-by: Your Name <12345+you@users.noreply.github.com>
```

- You may use your GitHub **noreply** address (GitHub → Settings → Emails): it keeps your e-mail address private.
- Forgot it? Sign off the last commit with `git commit --amend -s --no-edit`, or all commits of your branch with
  `git rebase --signoff main`, then `git push --force-with-lease`.
- Pull requests with commits that are not signed off cannot be merged.

**AI-assisted work is welcome.** Much of Gökyüzü was written with AI coding assistants. If you use one, you are still
the author who signs off: read and test everything you submit, and make sure it does not reproduce someone else's
code or text.

## What your contribution is licensed under

| You contribute | Licence |
|---|---|
| Code, shaders, scripts (including the Blender and audio scripts that generate the assets), docs | Apache License 2.0, like the rest of the code ([LICENSE](LICENSE), section 5) |
| A finished asset file you made (sound, image, texture, model) | CC BY 4.0; the project ships it in its CC BY-NC 4.0 asset pack with your credit ([ASSETS-LICENSE.md](ASSETS-LICENSE.md)) |
| Map data in `data/` | ODbL 1.0 ([data/README.md](data/README.md)) |

Almost every asset is generated by a script: to change how an aircraft, a building or a sound looks or sounds, change
the script that makes it, and include a screenshot or a recording of your local build in the pull request.

Third-party material is only accepted with a licence that allows this, and it must be listed in [NOTICE](NOTICE):

- **Map data:** free and openly licensed sources only, such as OpenStreetMap, Overture Maps, Copernicus, EMODnet or
  public-domain government data. **Never** Google, Apple, Bing, Esri, Mapbox or other key-gated, paid or restrictive
  sources, and no tracing from them.
- **No third-party logos, liveries or brand artwork.** Airline logos, real liveries, military unit badges and company
  lettering are trademarks. Use the project's fictional livery, or generic markings.
- **No copied text** from manuals or books beyond short, cited quotations. Describe the behaviour in your own words.
- **Sounds:** our own synthesis (`tools/audio/`) first. Recordings may be used to *measure* levels and spectra only,
  not shipped, unless their licence allows it.

## Code style

- **Match the surrounding code.** There is no formatter or linter configuration: read the file you change and follow
  it (JavaScript: ES modules, 2-space indentation, single quotes, semicolons; Python: 4 spaces, single quotes).
- **Comments explain why,** and each module starts with a comment saying what it does and whom it talks to. Keep them
  up to date when you change the behaviour.
- **The contracts are the architecture:** [CONTRACTS-SF.md](CONTRACTS-SF.md) (coordinates, interfaces, Blender rules,
  telemetry, missions) and [CONTRACTS-IST.md](CONTRACTS-IST.md) (adding a map). Keep them true: update them in the
  same pull request when you change an interface.
- **No new runtime dependencies** without discussing them in an issue first. The game ships three.js and nothing else.
- **Player-facing text is Turkish** with correct diacritics (ç, ğ, ı, İ, ö, ş, ü, and â / î where standard, as in
  "rüzgâr", "resmî"). Code, comments, commit messages and docs are in English.
- **Commits:** one topic per commit, a subject that says what changed where (see `git log`), signed off.
- **Generated files stay out of git:** `assets/`, `dist/`, `renders/`, downloaded raw data and caches (see
  `.gitignore`). Commit the script that makes a file, not the file.

## Tests

The tests are plain Node scripts with no framework. Each prints a PASS / FAIL table and exits with 1 on a failure:

```sh
for f in tests/*.test.mjs; do node "$f" || exit 1; done
```

- Flight models, missions, navigation, frame pacing, the leaderboard, maps and asset URLs are tested without a
  browser, against fake worlds.
- `packs`, `terrain` and parts of `assets` check the built assets and skip what is not present.
- Browser-level checks use Playwright scripts in `tools/qa/` (menu, take-off, approach, helicopter) and `tools/perf/`.
- Continuous integration runs the test suites on every pull request. See the README's "Tests and CI" section.

Add tests with your change when the behaviour can be checked in Node.

## Performance rules

**Phones first.** About 40 % of play sessions are on phones and tablets, and many desktop players use Windows laptops
with integrated graphics. A change that is fine on a desktop GPU can make the game unplayable on an iPhone.

- **No per-frame allocations** in the main loop, the HUD, the flight models or streaming code (no new arrays, objects
  or closures per frame). **No blocking work** during flight: compiles, big texture uploads and parsing belong behind
  the loading screen or in small per-frame budgets.
- **Load lazily:** code that not every player needs goes into its own chunk (`import()`), as missions and avionics do.
- **Stay within the budgets of each quality class** (low / phone, medium / tablet and integrated GPUs, high, ultra):
  draw calls, triangles, texture memory and the first-playable download. A new map stays within San Francisco's numbers
  at the same quality (CONTRACTS-IST.md §5).
- **Measure, don't guess.** The tools are in [`tools/perf/`](tools/perf) and described in
  [docs/perf/plan.md](docs/perf/plan.md) §9; the device matrix and findings are in
  [docs/perf/findings-2026-09.md](docs/perf/findings-2026-09.md):

  ```sh
  npx playwright install chromium webkit          # once
  export PERF_BASE=http://localhost:5173/         # the tools default to :5195, a clean worktree of the baseline
  node tools/perf/matrix.mjs --profiles phone-cpu4,tablet-webkit,laptop-igpu --maps sf,ist   # device matrix
  node tools/perf/soak.mjs --map ist --profile phone-cpu4                                    # 10-minute flight
  node tools/perf/ab.mjs --variants "…"           # interleaved A/B of two variants (see its header)
  ```

  Compare against a baseline served from a clean worktree of the commit before your change (plan.md §9 shows how).
  Put the before / after numbers and the command that produced them in the pull request.
- **Quality gate for visual changes:**

  ```sh
  node tools/perf/refshots.mjs gate --base http://localhost:5173/    # needs Python 3 with numpy and Pillow
  ```

  It captures fixed poses on each device class and map and compares them with the reference set in
  `docs/perf/ref-2026-09/` (SSIM against the measured noise floor; exit code 1 on a failure). Changes that should not
  change the image must pass. Changes that intentionally change it (texture sizes, LOD, draw distance, lighting)
  attach the heat maps for review.
- Test on a **real phone** when you can: Safari on iOS and Chrome on Android behave differently from desktop emulation.

## Privacy rules

Gökyüzü collects anonymous usage statistics only, and it must stay that way.

- **Telemetry** (`src/core/telemetry.js`, CONTRACTS-SF.md §11): events carry short codes and numbers (aircraft,
  mission id, stars, seconds, frame rate). Never add personal data: no nicknames, free text, precise positions tied to
  a person, device fingerprints, stored identifiers or cookies. Telemetry stays off on `localhost`, with
  `?telemetry=0`, and under Do Not Track / Global Privacy Control.
- **No third-party requests from the game page:** no analytics or ad SDKs, CDNs, web fonts or embeds. Everything is
  served from the game's own origin.
- **The leaderboard** stores a salted hash of a random browser key, never an IP address. Nicknames are optional,
  short and filtered.
- **Tools that download data** send a generic User-Agent, such as `gokyuzu-sf-pipeline/1.0`: never your name or e-mail
  address. Keep API keys in your environment or `~/.config`, never in the repository.
- **Nothing personal in commits:** no e-mail addresses (use the noreply address for sign-offs if you like), local
  absolute paths, IP addresses (tests use the documentation ranges `192.0.2.0/24`, `198.51.100.0/24`,
  `203.0.113.0/24` and `2001:db8::/32`), secrets, logs with visitor data, or screenshots showing personal information.

## Proposing missions and maps

**Missions.** Open a *Feature request or mission idea* issue with the map, aircraft, start, objectives in order,
success and failure conditions and the level (1–3). Missions are data plus small objective functions:

- San Francisco: `src/missions/catalog.js`, free-flight challenges in `src/missions/challenges.js`
  (CONTRACTS-SF.md §12 and §12.1);
- İstanbul: `src/missions/ist/catalog.js` and `src/missions/ist/challenges.js` (CONTRACTS-IST.md §6.M);
- new objective types: `src/missions/objectives.js` (allocation-free, evaluated from the flight state);
- leaderboard rules: `infra/leaderboard/build_rules.mjs`;
- tests: `tests/missions.test.mjs` and `tests/missions-ist.test.mjs` fly the missions with the real flight models.

Mission ids are `<name>` in San Francisco and `ist-<name>` in İstanbul. Briefings and results are Turkish player text.
Markers stay plain and cheap: no new heavy assets.

**Maps.** A new map is a large project (terrain, imagery, city, airports, landmarks, missions), so start with an issue.
[CONTRACTS-IST.md](CONTRACTS-IST.md) is the template, because İstanbul was added that way: a region frame
(`data/<id>/region.json`), free data sources only, every pipeline run with `GEO_REGION=<id>`, the same asset layout
under `assets/<id>/`, a lazily loaded map module `src/maps/<id>.js` registered in `src/maps/index.js`, and San
Francisco's performance budgets. Smaller scenery fixes (a missing landmark, a wrong runway) are welcome at any time.

## Pull request checklist

The [pull request template](.github/PULL_REQUEST_TEMPLATE.md) repeats this:

- commits signed off (DCO);
- all test suites pass;
- screenshots or a video for visual changes, performance numbers for performance-sensitive changes;
- no personal data, secrets or third-party logos; new third-party material listed in NOTICE.

## Türkçe

Katkın için teşekkürler! Kısaca:

- **Kurulum:** Node.js 20+, sonra `npm install`. Oyun dosyaları git'te değildir: `node tools/assets/fetch_pack.mjs`
  markasız varlık paketini GitHub Releases'tan indirip doğrular, ardından `node tools/serve.mjs` çalıştır. Hızlı
  başlangıç için `node tools/serve.mjs --assets-from https://fs.erenailab.com` yalnızca oyunun istediği dosyaları
  canlı siteden bir kez indirir; toplu indirme yapma lütfen. Adres: http://localhost:5173/.
- **DCO:** Her commit'i `git commit -s` ile imzala. Böylece katkıyı proje lisanslarıyla gönderme hakkın olduğunu
  onaylarsın. E-posta adresini gizli tutmak için GitHub'ın noreply adresini kullanabilirsin.
- **Lisans:** Kod Apache-2.0, kendi yaptığın varlık dosyaları CC BY 4.0 (proje bunları CC BY-NC 4.0 lisanslı, markasız
  görsel/ses paketinde senin adınla dağıtır), `data/` altındaki harita verisi ODbL. Bir modeli ya da sesi değiştirmek
  için çoğu zaman onu üreten betiği değiştirmek yeterlidir.
- **Kod stili:** Çevredeki koda uy. Oyuncunun gördüğü metinler doğru Türkçe karakterlerle (ç, ğ, ı, İ, ö, ş, ü)
  yazılır; kod, yorumlar ve commit mesajları İngilizcedir.
- **Testler:** `for f in tests/*.test.mjs; do node "$f" || exit 1; done` komutu hatasız bitmeli.
- **Performans:** Önce telefon. Kare başına bellek ayırma yok; ölçmeden iddia yok (`tools/perf/`). Görsel değişikliklerde
  `node tools/perf/refshots.mjs gate --base http://localhost:5173/` kalite kapısını çalıştır.
- **Gizlilik:** İstatistiklere kişisel veri eklenmez; oyun sayfası üçüncü taraf sunuculara istek göndermez; araçlar
  genel bir User-Agent kullanır (`gokyuzu-sf-pipeline/1.0`), asla adını ya da e-postanı değil.
- **Görev ve harita önerileri:** "Feature request or mission idea" şablonuyla issue aç. Görevler için CONTRACTS-SF.md
  §12 ve CONTRACTS-IST.md §6.M, yeni haritalar için CONTRACTS-IST.md yol gösterir.
- **Güvenlik açıkları:** Herkese açık issue yerine GitHub'da Security → "Report a vulnerability" (SECURITY.md).
